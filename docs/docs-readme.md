# Docs README

This directory contains repository documentation, including the [detailed local-development reference](developer_guide.md). Files here are not automatically copied to [armadaproject.io](https://armadaproject.io).

Published website content lives in [`website/content/`](../website/content/). For example, the published developer setup page is edited in [`website/content/docs/developer-guide.mdx`](../website/content/docs/developer-guide.mdx).

Follow [`website/README.md`](../website/README.md) for website authoring, navigation, assets, preview, checks and publication. The [website workflow](../.github/workflows/website.yml) builds the current site and publishes its static export through GitHub Actions; no manual edits to a publication branch are needed.
